SD card / FAT32

Lists external physical disks. Formatting erases the entire disk (MBR, one FAT32 partition). For 64 KiB clusters use the CLI with sudo: sudo ./sak fat32 diskN --confirm diskN --cluster-64k.

Lists removable drives. Formatting opens the bundled FAT32 Format tool (guiformat), as SAK did: pick the SD card's drive letter there, choose 64K allocation units for the Switch, and confirm in that window.
